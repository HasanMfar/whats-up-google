# اسکنر دسترسی گوگل برای اشتراک‌های وی‌۲ری 🛰️

اشتراک وی‌۲ری شما هیچ‌وقت یکدست تمیز نیست — بعضی کانفیگ‌ها را گوگل پرچم‌گذاری یا مسدود می‌کند و بعضی سالم‌اند. این ابزار اشتراک شما را **کانفیگ به کانفیگ** بررسی می‌کند: برای هر نود، درخواست‌های واقعی از طریق خودِ همان نود فرستاده می‌شود تا معلوم شود گوگل اجازهٔ دسترسی به این سرویس‌ها را می‌دهد یا نه:

- **جستجوی گوگل** — تشخیص صفحهٔ کپچا / «ترافیک غیرعادی»
- **جمینای وب** (gemini.google.com)
- **جمینای API** (generativelanguage.googleapis.com)
- **آنتی‌گرَویتی** (antigravity.google)

و در پایان، **کانفیگ‌های تمیز را دستی جدا می‌کند** و برایتان اشتراک قابل‌ایمپورت می‌سازد.

## شروع سریع (ویندوز) — سه قدم

**۱.** روی **`run.bat`** دوبار کلیک کنید.
فقط بار اول: پکیج‌های پایتون نصب و هستهٔ Xray به‌صورت خودکار دانلود می‌شود.

**۲.** `subscriptions.txt` در نوت‌پد باز می‌شود — آدرس اشتراک‌هایتان را بگذارید (هر خط یک آدرس)، ذخیره و ببندید. اسکن خودش شروع می‌شود.

**۳.** جدول زنده را تماشا کنید: هر کانفیگ با **آیدی (ID)**، سرور، کشور خروجی، تأخیر و نتیجهٔ تک‌تک بررسی‌ها. بعد از پایان، فایل آمادهٔ ایمپورت را در v2rayN بگذارید.

## کدام فایل را ایمپورت کنم؟

| فایل | محتوا |
|------|-------|
| `best_subscription.txt` | ⭐ **از اینجا شروع کنید** — سریع‌ترین کانفیگ به‌ازای هر IP سالم، مرتب بر اساس تأخیر، برای جمینای/آنتی‌گرَویتی |
| `clean_subscription.txt` | کانفیگ‌هایی که **همهٔ** بررسی‌ها را پاس کردند |
| `gemini_subscription.txt` | برای جمینای (وب + API) قابل‌استفاده — حتی اگر جستجوی گوگل کپچا بدهد |
| `antigravity_subscription.txt` | برای آنتی‌گرَویتی قابل‌استفاده |

هر فایل base64 است و مستقیم قابل ایمپورت در v2rayN (یا هر کلاینت وی‌۲ری). نسخهٔ `*_links.txt` همان نودها به‌صورت لینک خام است. گزارش کامل (IP خروجی، کشور، ISP/ASN، وضعیت هر بررسی و دلیل مسدودی) در پوشهٔ `reports/` ذخیره می‌شود — فرمت JSON و CSV.

## نتیجهٔ هر کانفیگ

| نتیجه | معنی |
|-------|------|
| `CLEAN` ✅ | همهٔ بررسی‌ها پاس شد — گوگل این نود را پرچم نکرده |
| `FLAGGED` ⛔ | حداقل یک بررسی مسدود شد (کپچا / محدودیت منطقه / خطای موقعیت مکانی) |
| `DEAD` 💀 | هیچ درخواستی از طریق نود رد نشد — نود قطع است |
| `ERROR` ⚠️ | نود جواب داد ولی یک بررسی خطا خورد — دوباره اجرا کنید |

## تشخیص مسدودی چگونه کار می‌کند؟

- **جستجو**: هدایت‌شدن به صفحهٔ `/sorry` یا وجود نشانه‌های کپچا در پاسخ
- **جمینای وب**: کد ۴۰۳، صفحهٔ «در کشور شما در دسترس نیست» یا مسیر `/unsupported`
- **جمینای API**: خطای `User location is not supported for the API use` (هر خطای دیگری — مثلاً نبود کلید API — یعنی موقعیت مکانی پذیرفته شده و نود تمیز است)
- **آنتی‌گرَویتی**: کد ۴۰۳/۴۲۹ یا صفحهٔ مسدودی

بررسی‌ها به‌صورت **موازی** روی هر نود اجرا می‌شوند و به‌صورت پیش‌فرض ۲۰ نود همزمان تست می‌شود — پس اسکن سریع تمام می‌شود.

## بعد از هر اجرا

- ابزار **لیست همهٔ فایل‌های ساخته‌شده** را با مسیر و حجم چاپ می‌کند — گزارش‌های JSON/CSV به‌همراه هر اشتراک انتخاب‌شده‌ای که نوشته شده است.
- اشتراکی که لینک V2Ray برنگرداند (صفحهٔ HTML، لیست کد و…) **با خطای واضح رد می‌شود** و پیش‌نمایش ۱۵۰ نویسه‌ایِ محتوای برگشتی را نشان می‌دهد — بی‌صدا رد نمی‌شود.
- تنظیمات در `config.json` است (concurrency، timeout، روشن/خاموش‌کردن هر بررسی). این فایل یک بار با پیش‌فرض‌ها ساخته می‌شود و **بعد از آن هرگز بازنویسی نمی‌شود** — اولویت: پیش‌فرض‌ها ← `config.json` ← فلگ‌های خط فرمان.

## از ترمینال (اختیاری)

```bash
python -m scanner                  # اسکن کامل
python -m scanner --dry-run        # فقط لیست کانفیگ‌ها و آیدی‌ها، بدون تست
python -m scanner --concurrency 40 # تست همزمان ۴۰ نود (پیش‌فرض ۲۰)
python -m scanner --skip search    # حذف یک بررسی: search/gemini/gemini_api/antigravity
python -m scanner --watch 30       # تکرار اسکن هر ۳۰ دقیقه
python -m scanner --file links.txt # اسکن از یک فایل محلی لینک‌ها
python -m scanner --check-xray     # فقط دانلود/بررسی هستهٔ Xray
```

## ساختار پروژه

```
scanner/
├── nodes.py           # پارس لینک‌های vmess / vless / trojan / ss + استخراج آیدی
├── subscriptions.py   # دریافت و دیکد اشتراک‌ها (base64 و متن خام)
├── xray.py            # دانلود خودکار هستهٔ Xray + اجرای یک پروسه برای هر نود
├── probes.py          # چهار بررسی گوگل به‌صورت موازی از طریق SOCKS
├── clean_sub.py       # انتخاب دستی کانفیگ‌های تمیز و ساخت اشتراک خروجی
├── report.py          # جدول زنده + گزارش JSON/CSV
└── main.py            # ورودی CLI و هماهنگی اسکن
```

## مشکلات رایج

- **دانلود Xray ناموفق است** (گیت‌هاب روی شبکهٔ شما باز نمی‌شود): متغیر محیطی `HTTPS_PROXY` را ست کنید، یا در `config.json` مسیر `xray.exe` خودتان — مثلاً از داخل پوشهٔ v2rayN — را در `xray_path` قرار دهید.
- **خطای «SOCKS port is already in use»**: پروسه‌های xray.exe به‌جامانده از اسکن قبلی هنوز روشن‌اند؛ آن‌ها را از Task Manager ببندید یا `socks_port_start` را در `config.json` عوض کنید.
- **پیام «subscription did not return V2Ray links»**: آن آدرس، اشتراک V2Ray نیست (صفحه، لیست کد یا خروجی کلاینت دیگر است) — آدرس را عوض کنید؛ پیش‌نمایش محتوای برگشتی در همان خطا آمده است.
- **خیلی از نودها DEAD شدند**: احتمالاً اشتراک قدیمی است؛ `--dry-run` را اجرا کنید تا ببینید کانفیگ‌ها درست پارس شده‌اند یا نه.

## نکته

این ابزار فقط برای بررسی اشتراک‌های خودتان است و کاری با دورزدن سیستم‌های تشخیص ندارد — صرفاً وضعیت هر کانفیگ را همان‌طور که گوگل پاسخ می‌دهد ثبت می‌کند.

## سلب مسئولیت

این پروژه با کمک **ZCode** (دستیار کدنویسی مبتنی بر هوش مصنوعی) نوشته شده است و «همان‌گونه که هست» ارائه می‌شود — بدون هیچ‌گونه ضمانت. پیش از استفاده، کد را مرور کنید.

این ابزار صرفاً برای استفادهٔ شخصیِ کاربرانی است که محدودیت‌های اعمالی گوگل برایشان (محدودیت منطقه‌ای، کپچا، خطای موقعیت مکانی) مزاحمت ایجاد می‌کند: بررسی می‌کند که این محدودیت‌ها روی کانفیگ‌های اشتراک خودِ کاربر چه اثری دارند. **این کد خودش هیچ فیلترشکنی نیست** — هیچ پروکسی هم ارائه نمی‌دهد و فقط کانفیگ‌هایی را که کاربر از قبل دارد تست می‌کند.
